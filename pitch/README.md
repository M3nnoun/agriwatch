# 🎤 AgriWatch Pitch Deck

A [Reveal.js](https://revealjs.com) presentation, branded to match the app (AgriWatch emerald).

## Files
- **`index.html`** — the slides (13). Open in any browser.
- **`SCRIPT.md`** — the full speaker script, timing, and likely judge Q&A.

## Present it
1. Double-click **`index.html`** (Chrome / Edge / Firefox). *Needs internet — Reveal.js + fonts load from CDN.*
2. Press **`F`** for fullscreen.
3. Press **`S`** for **speaker view** — your script (already embedded per slide) shows beside a timer.

### Keys
| Key | Action |
|---|---|
| `→` / `Space` | Next slide / reveal next point |
| `←` | Back |
| `S` | Speaker notes window |
| `F` | Fullscreen |
| `Esc` / `O` | Slide overview |
| `B` | Black-out screen (for pausing) |

## Export to PDF
Open with `?print-pdf` appended, then Print → Save as PDF:
```
index.html?print-pdf
```
Set margins to *None* and enable *Background graphics* in the print dialog.

## Tip
The whole pitch rests on one line — **"$15 hits a farmer's phone the instant the satellite confirms drought."**
On slide 7, if you can, alt-tab to the running app at `localhost:3000/simulate` and run it live for ~30s. That single demo wins rooms.
